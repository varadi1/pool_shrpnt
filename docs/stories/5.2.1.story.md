# Story 5.2.1: Contract Management Page Implementation

## Status
go

## Story
**As an** Admin or PM,
**I want** to view, search, and manage contracts through a dedicated Contract management page,
**so that** I can maintain contract information and enable the Order creation wizard to reference valid contracts

## Acceptance Criteria
1. Contract list page displays all contracts the user has permission to view (NEU_Admin sees all; PM sees assigned)
2. Table displays key contract fields: number, name, client, status, start/end dates, PM assignment
3. Search/filter functionality by contract number, name, client, or status
4. Sorting capability on all table columns
5. Pagination with configurable page size (10/25/50 items)
6. Contract detail view accessible by clicking on a contract row
7. Create new contract button visible only to NEU_Admin role
8. Edit/Delete actions available only to NEU_Admin role
9. Status badge colors: green (active), gray (inactive), blue (completed)
10. Loading states and error handling with correlation IDs
11. Responsive design that works on tablets and desktop screens
12. Keyboard navigation support for accessibility
13. Export to CSV functionality for visible contracts
14. Real-time status updates when contracts expire
15. Integration with existing authentication and role-based access control

  ```typescript
  // Error handling with correlation ID and retry logic
  const handleApiError = (error: any): never => {
    const correlationId = error.response?.headers?.['x-correlation-id'];
    const message = error.response?.data?.detail || 'An unexpected error occurred';
    
    // Log error with correlation ID
    console.error(`API Error [${correlationId}]:`, error);
    
    // Show user-friendly error with correlation ID
    toast.error(`Error: ${message} (Ref: ${correlationId})`);
    
    throw new Error(`${message} [${correlationId}]`);
  };
  
  // Retry logic for transient failures
  const retryableRequest = async <T>(
    request: () => Promise<T>,
    maxRetries = 3
  ): Promise<T> => {
    let lastError: any;
    
    for (let attempt = 0; attempt < maxRetries; attempt++) {
      try {
        return await request();
      } catch (error: any) {
        lastError = error;
        
        // Don't retry 4xx errors (except 429)
        if (error.response?.status >= 400 && 
            error.response?.status < 500 && 
            error.response?.status !== 429) {
          throw error;
        }
        
        // Exponential backoff
        const delay = Math.min(1000 * Math.pow(2, attempt), 10000);
        await new Promise(resolve => setTimeout(resolve, delay));
      }
    }
    
    throw lastError;
  };
  ```

**React Query Caching Strategy**
```typescript
// Caching configuration for contracts
const contractsQuery = useQuery({
  queryKey: ['contracts', filters],
  queryFn: () => contractsApi.getContracts(filters),
  staleTime: 5 * 60 * 1000, // Consider data stale after 5 minutes
  cacheTime: 10 * 60 * 1000, // Keep in cache for 10 minutes
  refetchOnWindowFocus: false,
  refetchOnMount: 'always'
});

// Optimistic updates for modifications
const updateContractMutation = useMutation({
  mutationFn: contractsApi.updateContract,
  onMutate: async (updatedContract) => {
    // Cancel outgoing refetches
    await queryClient.cancelQueries(['contracts']);
    
    // Snapshot previous value
    const previousContracts = queryClient.getQueryData(['contracts']);
    
    // Optimistically update
    queryClient.setQueryData(['contracts'], (old) => 
      old.map(c => c.id === updatedContract.id ? updatedContract : c)
    );
    
    return { previousContracts };
  },
  onError: (err, newContract, context) => {
    // Rollback on error
    queryClient.setQueryData(['contracts'], context.previousContracts);
  },
  onSettled: () => {
    // Refetch after mutation
    queryClient.invalidateQueries(['contracts']);
  }
});
```
