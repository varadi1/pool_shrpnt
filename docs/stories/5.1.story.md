# Story 5.1: Admin Dashboard and Navigation Shell

## Status
Draft

## Story
**As an** Admin or PM,
**I want** to access a centralized dashboard with navigation to all administrative functions,
**so that** I can efficiently manage orders, templates, permissions, and monitor system status from a single interface

## Acceptance Criteria
1. Dashboard loads in less than 3 seconds (P95) with role-based content display
2. Navigation menu provides access to all admin functions based on user role (RBAC)
3. Dashboard displays key metrics: active orders, pending provisions, recent activities, system health
4. MSAL authentication integrated with automatic token renewal and role claims
5. Responsive layout works on desktop (1920x1080) and tablet (1024x768) resolutions
6. Navigation persists across page transitions with active route highlighting
7. User profile menu shows current user, role, and logout option
8. All UI components follow Fluent UI design system with WCAG 2.2 AA compliance
9. Error states handled gracefully with correlation ID display for troubleshooting

**Dashboard Metrics Specification**
```typescript
interface DashboardMetrics {
  orders: {
    active: number;        // Orders in progress
    pending: number;       // Awaiting provision
    failed24h: number;     // Failed in last 24 hours
    total: number;         // Total this month
  };
  contracts: {
    active: number;        // Active contracts
    expiring30d: number;   // Expiring in 30 days
  };
  locks: {
    timeLocked: number;    // Time-based locks active
    crUnlocked: number;    // CR unlocks active
    manualLocked: number;  // Manual locks active
  };
  guests: {
    active: number;        // Active guest users
    expiring7d: number;    // Expiring in 7 days
  };
  system: {
    health: 'healthy' | 'degraded' | 'unhealthy';
    queueDepth: number;    // Pending background jobs
    lastProvisionTime: number; // Minutes
  };
}
```
