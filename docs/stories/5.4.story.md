# Story 5.4: Permissions Manager with RBAC Matrix Editor

## Status
Draft

## Story
**As an** Admin or PM,
**I want** to manage user permissions, groups, and role assignments through a visual interface with inheritance control and exception handling,
**so that** I can ensure proper access control following the RBAC matrix while handling special cases like financial segregation and NEU-only folders

## Acceptance Criteria
1. Admin can view and edit the permissions matrix for any order (EM)
2. System enforces role-based permissions according to the defined RBAC matrix
3. Permission inheritance can be broken at specific folder levels (sensitive folders)
4. Financial and NEU-only folder segregation is automatically enforced
5. PM can manually lock/unlock folder groups with reason tracking
6. Changes to permissions are applied within 1 minute to SharePoint/Teams
7. All permission changes are audited with actor, timestamp, and reason
8. Visual interface shows effective permissions per user/group/folder combination
9. Bulk permission operations support multiple users/folders simultaneously
10. Permission conflicts are detected and resolution options provided

### Permission Calculation Algorithm
```typescript
// permissionCalculator.ts
class PermissionCalculator {
  /**
   * Calculate effective permission for user/folder combination
   * Precedence: Explicit > Role > Group > Inherited
   */
  calculateEffective(
    userId: string,
    folderId: string,
    matrix: PermissionMatrix
  ): EffectivePermission {
    const sources: PermissionSource[] = [];
    
    // 1. Check explicit assignments (highest priority)
    const explicit = this.getExplicitPermission(userId, folderId);
    if (explicit) {
      sources.push({ 
        type: 'explicit', 
        level: explicit.level, 
        priority: 1,
        sourceName: 'Direct assignment'
      });
    }
    
    // 2. Check role-based permissions
    const role = this.getUserRole(userId);
    const rolePermission = this.getRolePermission(role, folderId);
    if (rolePermission) {
      sources.push({
        type: 'role',
        level: rolePermission.level,
        priority: 2,
        sourceName: role
      });
    }
    
    // 3. Check group memberships
    const groups = this.getUserGroups(userId);
    groups.forEach(group => {
      const groupPerm = this.getGroupPermission(group, folderId);
      if (groupPerm) {
        sources.push({
          type: 'group',
          level: groupPerm.level,
          priority: 3,
          sourceName: group.name
        });
      }
    });
    
    // 4. Check inherited permissions (unless broken)
    const folder = this.getFolder(folderId);
    if (folder.inheritanceState !== 'broken') {
      const inherited = this.getInheritedPermission(userId, folder.parentId);
      if (inherited) {
        sources.push({
          type: 'inherited',
          level: inherited.level,
          priority: 4,
          sourceName: 'Parent folder'
        });
      }
    }
    
    // 5. Resolve conflicts
    const resolved = this.resolveConflicts(sources);
    
    return {
      userId,
      folderId,
      calculatedLevel: resolved.level,
      sources,
      conflicts: resolved.conflicts
    };
  }
  
  private resolveConflicts(sources: PermissionSource[]): {
    level: PermissionLevel;
    conflicts?: PermissionConflict[];
  } {
    if (sources.length === 0) {
      return { level: 'none' };
    }
    
    // Sort by priority (lower number = higher priority)
    sources.sort((a, b) => a.priority - b.priority);
    
    // Check for conflicts at same priority level
    const conflicts = this.detectConflicts(sources);
    
    if (conflicts.length > 0) {
      // Apply conflict resolution rules
      return this.applyConflictResolution(conflicts);
    }
    
    // Return highest priority permission
    return { level: sources[0].level };
  }
}
```

### Conflict Resolution Rules
```typescript
interface ConflictResolutionRules {
  precedence: [
    'explicit',     // 1. Direct user assignment
    'role',         // 2. Role-based assignment
    'group',        // 3. Group membership
    'inherited'     // 4. Parent folder inheritance
  ];
  
  sameLevelRules: {
    // When multiple sources at same level conflict
    strategy: 'most_permissive' | 'least_permissive' | 'manual';
    default: 'most_permissive';
  };
  
  specialCases: [
    {
      condition: 'folder.isFinancial && user.role !== "NEU_Admin"',
      override: 'none',
      reason: 'Financial segregation policy'
    },
    {
      condition: 'folder.isNeuOnly && !user.isNEU',
      override: 'none',
      reason: 'NEU-only folder restriction'
    },
    {
      condition: 'folder.isLocked && lockType === "manual"',
      override: 'read',
      reason: 'Manual lock applied'
    }
  ];
}
```
