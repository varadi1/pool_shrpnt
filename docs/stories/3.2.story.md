# Story 3.2: Scheduled Lock Evaluation and State Transitions

## Status
Approved

## Story
**As a** System Administrator,
**I want** the system to automatically evaluate and apply lock state transitions based on configured rules,
**so that** time-based access controls are enforced consistently without manual intervention

## Acceptance Criteria
1. Scheduler runs every 15 minutes to evaluate lock rules for all active EMs
2. Lock state transitions are applied based on T-window calculations (T-3, T-1, T+0, etc.)
3. State transitions follow the lifecycle: Full access → Limited → Read-only
4. Concurrent scheduler runs are prevented using distributed locks
5. Partial failures are handled with retry logic and compensation
6. All state transitions trigger appropriate events for downstream systems
7. Scheduler performance: process 1000+ EMs within 5-minute window
8. State reconciliation ensures SharePoint permissions match desired state

### State Transition Logic
Priority order for lock states:
1. **CR Lock** (from Story 3.5) - Highest priority
2. **Manual Lock** (from Story 3.3) - Override automatic
3. **Time-based Lock** (this story) - Default behavior

State transition rules:
```python
# T-window states
T_MINUS_8_OR_EARLIER = "full_access"     # Before readonly window
T_MINUS_7_TO_MINUS_1 = "limited_access"  # Remediation window
T_0_TO_T_PLUS_7 = "upload_window"        # Upload window
T_PLUS_8_OR_LATER = "readonly"           # After deadline

# Transition conditions
def determine_lock_state(em, current_time):
    if has_active_cr(em):
        return get_cr_state(em)
    if has_manual_lock(em):
        return get_manual_state(em)
    return calculate_time_based_state(em, current_time)
```

### Graph API Integration
Reuse existing Graph client from SharePoint integration:
```python
from api.services.sharepoint.graph_client import get_graph_client

async def apply_lock_state(site_id: str, drive_id: str, folder_id: str, state: str):
    """Apply lock state to SharePoint folder"""
    graph = await get_graph_client()
    
    if state == "readonly":
        permissions = {"roles": ["read"]}
    elif state == "limited_access":
        permissions = {"roles": ["read", "write"]}
    else:  # full_access
        permissions = {"roles": ["read", "write", "delete"]}
    
    # Update permissions via Graph API
    await graph.sites[site_id].drives[drive_id].items[folder_id].permissions.update(permissions)
```
