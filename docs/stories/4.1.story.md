# Story 4.1: Guest User Invitation and Group Assignment

## Status
Ready for Review

## Story
**As an** Admin,
**I want** to invite guest users via Azure AD B2B and assign them to appropriate groups,
**so that** external partners can access relevant Teams/SharePoint resources with proper permissions

## Acceptance Criteria
1. Admin can invite guest users by email address through the poolDRV web interface
2. Guest invitation is processed via Azure AD B2B using Microsoft Graph API
3. Guest users are automatically assigned to appropriate Azure AD groups based on their partner company and role
4. Invitation includes customizable email template with onboarding instructions
5. System tracks invitation status (pending/accepted/expired) and displays in UI
6. Failed invitations are retried with exponential backoff for Graph API rate limits
7. All guest operations are audited with events: GUEST_INVITED, GUEST_ACCEPTED, GUEST_ASSIGNED
8. Guest access is granted within 15 minutes of invitation acceptance

### Group Assignment Rules
**Automatic Group Assignment Logic:**
```python
# Group assignment based on partner company and role
GROUP_ASSIGNMENT_RULES = {
    "partner_expert": [
        "experts_group",              # Base expert group
        "partner_{partner_id}_experts", # Partner-specific expert group
        "project_{em_id}_readers"      # Project-specific read access
    ],
    "partner_admin": [
        "partner_admins",              # Base admin group
        "partner_{partner_id}_admins",  # Partner-specific admin group
        "project_{em_id}_contributors"  # Project-specific write access
    ],
    "partner_viewer": [
        "partner_{partner_id}_viewers",  # Partner-specific viewer group
        "project_{em_id}_readers"       # Project-specific read-only access
    ],
    "neu_pm": [
        "neu_project_managers",         # NEÜ PM group
        "project_{em_id}_owners"        # Full project control
    ]
}

def get_groups_for_assignment(partner_company_id: str, role: str, em_id: str = None):
    """Determine groups to assign based on partner and role"""
    rule_template = GROUP_ASSIGNMENT_RULES.get(role, [])
    groups = []
    
    for template in rule_template:
        group_name = template.format(
            partner_id=partner_company_id,
            em_id=em_id or "*"
        )
        groups.append(group_name)
    
    return groups
```
