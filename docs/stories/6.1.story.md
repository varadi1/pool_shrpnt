# Story 6.1: Bidirectional Access Reports System

## Status
Draft

## Story
**As an** Admin or Compliance Officer,
**I want** to generate comprehensive access reports showing both folder-to-users and user-to-folders relationships with current permissions,
**so that** I can answer compliance questions about who has access to what resources and what resources each user can access

## Acceptance Criteria
1. Generate folder-to-users report showing all users/groups with access to selected folders
2. Generate user-to-folders report showing all folders accessible by selected users/groups
3. Reports display effective permissions considering role inheritance and exceptions
4. Filter reports by order (EM), partner company, role type, and permission level
5. Export reports to CSV and XLSX formats with proper formatting
6. Reports complete within 15 minutes for large datasets (10,000+ users, 50,000+ folders, 100,000+ permission entries)
7. Real-time permission calculation reflects current SharePoint state
8. Reports include both direct and inherited permissions with clear distinction
9. Scheduled report generation with email delivery
10. Report results are cached for improved performance on repeated queries
