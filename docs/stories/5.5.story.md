# Story 5.5: Audit View and Event Tracking System

## Status
go

## Story
**As an** Admin or Compliance Officer,
**I want** to view, search, and export a comprehensive audit trail of all system actions and changes,
**so that** I can track user activities, investigate issues, ensure compliance, and maintain a complete record of system events for regulatory requirements

## Acceptance Criteria
1. Audit view displays all system events in chronological order with pagination
2. Advanced search and filtering by date range, user, action type, entity, and correlation ID
3. Audit entries show actor, timestamp, action, target entity, changes (before/after), and correlation ID
4. Export functionality to CSV and XLSX formats with filtered results
5. Audit log entries are immutable and retained for 7 years
6. Real-time updates show new audit events without page refresh
7. Detailed view for each audit entry with full context and related events
8. Performance: Load and filter audit logs within 3 seconds for up to 10,000 entries
9. Correlation view links related events across different services
10. Role-based access ensures only authorized users can view audit logs

### WebSocket Protocol Specification
```typescript
// auditWebSocket.ts
class AuditWebSocketService {
  private ws: WebSocket | null = null;
  private reconnectAttempts = 0;
  private maxReconnectAttempts = 5;
  private reconnectDelay = 1000; // Start with 1 second
  private pingInterval: NodeJS.Timeout | null = null;
  
  connect(): void {
    const wsUrl = `${config.ws.baseUrl}/audit/live`;
    this.ws = new WebSocket(wsUrl);
    
    this.ws.onopen = () => {
      console.log('WebSocket connected');
      this.reconnectAttempts = 0;
      this.reconnectDelay = 1000;
      this.startPingInterval();
    };
    
    this.ws.onmessage = (event) => {
      const message: WebSocketMessage = JSON.parse(event.data);
      this.handleMessage(message);
    };
    
    this.ws.onerror = (error) => {
      console.error('WebSocket error:', error);
      this.fallbackToPolling();
    };
    
    this.ws.onclose = () => {
      this.stopPingInterval();
      this.attemptReconnect();
    };
  }
  
  private attemptReconnect(): void {
    if (this.reconnectAttempts < this.maxReconnectAttempts) {
      this.reconnectAttempts++;
      setTimeout(() => {
        console.log(`Reconnection attempt ${this.reconnectAttempts}`);
        this.connect();
      }, this.reconnectDelay);
      
      // Exponential backoff with max 30 seconds
      this.reconnectDelay = Math.min(this.reconnectDelay * 2, 30000);
    } else {
      this.fallbackToPolling();
    }
  }
  
  private fallbackToPolling(): void {
    // Implement polling with 5 second intervals
    setInterval(async () => {
      const latestEvents = await auditService.getLatestEvents();
      this.processEvents(latestEvents);
    }, 5000);
  }
  
  private startPingInterval(): void {
    this.pingInterval = setInterval(() => {
      if (this.ws?.readyState === WebSocket.OPEN) {
        this.ws.send(JSON.stringify({ type: 'ping', timestamp: new Date().toISOString() }));
      }
    }, 30000); // Ping every 30 seconds
  }
}
```

interface ExportConfig {

    maxRowsPerExport: 50000;
    maxFileSizeMB: 100;
    chunkSize: 5000; // Process in chunks
  };

    strategy: 'cursor'; // Use cursor-based chunking

      // Process one chunk at a time
      const chunk = await auditService.getChunk(cursor, size);
      return chunk;
