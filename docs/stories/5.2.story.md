# Story 5.2: New Order Creation Form

## Status
go

## Story
**As an** Admin or PM,
**I want** to create new orders (EM) through a web form with template selection and partner assignment,
**so that** I can provision folder structures in SharePoint/Teams with proper permissions in under 10 minutes

## Acceptance Criteria
1. Multi-step wizard form guides through order creation process
2. Contract selection shows only contracts user has permission to manage (NEU_Admin sees all; PM sees assigned)
3. Template selection displays available templates with version information
4. Partner company selection allows multiple partners to be assigned
5. Part selection (A/B/C) and deadline configuration per part
6. Form validates all required fields before submission
7. Provisioning triggers on submit and completes within 10 minutes
8. Success/failure feedback with detailed status and audit trail
9. Form is keyboard navigable and WCAG 2.2 AA compliant
10. Order code is auto-generated and validated per naming convention (EM-{YEAR}-{CONTRACT_CODE}-{SEQUENCE})
11. Template preview shows folder tree with default permissions and lock indicators
12. Lock timeline visualization displays T-3/T-1/T+0/T+8 markers with tooltips and color coding
13. Progress view shows real-time provisioning steps and estimated time remaining
14. “Save as Draft” allows resuming within 7 days
15. At least one partner must be assigned; permissions configurable per folder and part
16. Error messages include a correlation ID; transient provisioning failures can be retried

const orderFormSchema = z.object({
  contractId: z.string().min(1, 'Contract is required'),

    .min(3, 'Order name must be at least 3 characters')
    .max(100, 'Order name too long')

  parts: z.array(z.object({

  })).min(1, 'At least one part required'),
  partners: z.array(z.object({
    companyId: z.string(),
    accessLevel: z.enum(['read', 'write', 'admin'])
  })).min(1, 'At least one partner required')
}).refine(data => data.endDate > data.startDate, {
  message: 'End date must be after start date',
  path: ['endDate']
});

**Error Recovery Strategy**
```typescript
// Retry failed provisions with exponential backoff
const retryProvision = async (orderId: string, attempt = 0): Promise<void> => {
  try {
    await api.post(`/api/orders/${orderId}/provision`);
  } catch (error) {
    if (attempt < 3 && isTransientError(error)) {
      const delay = Math.min(1000 * Math.pow(2, attempt), 10000);
      await new Promise(resolve => setTimeout(resolve, delay));
      return retryProvision(orderId, attempt + 1);
    }
    throw error;
  }
};
```
