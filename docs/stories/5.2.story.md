# Story 5.2: New Order Creation Form

## Status
Draft

## Story
**As an** Admin or PM,
**I want** to create new orders (EM) through a web form with template selection and partner assignment,
**so that** I can provision folder structures in SharePoint/Teams with proper permissions in under 10 minutes

## Acceptance Criteria
1. Multi-step wizard form guides through order creation process
2. Contract selection shows only contracts user has permission to manage
3. Template selection displays available templates with version information
4. Partner company selection allows multiple partners to be assigned
5. Part selection (A/B/C) and deadline configuration per part
6. Form validates all required fields before submission
7. Provisioning triggers on submit and completes within 10 minutes
8. Success/failure feedback with detailed status and audit trail
9. Form is keyboard navigable and WCAG 2.2 AA compliant

const orderFormSchema = z.object({

**Error Recovery Strategy**
```typescript
// Retry failed provisions with exponential backoff
const retryProvision = async (orderId: string, attempt = 0): Promise<void> => {
  try {
    await api.post(`/api/orders/${orderId}/provision`);
  } catch (error) {
    if (attempt < 3 && isTransientError(error)) {
      const delay = Math.min(1000 * Math.pow(2, attempt), 10000);
      await new Promise(resolve => setTimeout(resolve, delay));
      return retryProvision(orderId, attempt + 1);
    }
    throw error;
  }
};
```
